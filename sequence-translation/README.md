# DNA Sequence Translation and ORF Analysis

## Overview

This project implements fundamental DNA sequence analysis operations in Python, including reverse-complement generation and translation of nucleotide sequences into amino acid sequences across multiple reading frames.

The project was developed during graduate bioinformatics coursework to practice implementing core sequence-processing concepts programmatically rather than relying solely on existing bioinformatics software.

## Objectives

- Represent the standard genetic code programmatically in Python
- Generate and manipulate DNA sequences
- Calculate the reverse complement of a nucleotide sequence
- Translate nucleotide sequences into amino acid sequences
- Examine open reading frames (ORFs) across DNA strands
- Compare computational translation results with an established bioinformatics resource

## Implementation

The Python script defines the genetic code using a codon-to-amino-acid dictionary and performs sequence-processing operations directly in Python.

The workflow includes:

1. DNA sequence generation and processing
2. Reverse-complement calculation
3. Identification of reading frames
4. Codon-based translation into amino acid sequences
5. Examination of translated products for potential ORFs
